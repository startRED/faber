# g390w: correct the sole-subscription screen expectation

## Result

Corrected `names_while_streaming` in `testkit/src/screen/app.rs`: the Codex held recording expects
`reason.autoOnly`, not `reason.autoDefault`. Production behavior and locale strings are unchanged.
The product map and conversation design document now clarify this existing no-model-list case.

## Evidence and intended behavior

- Read `gh run view 42368895970 --log-failed`. Screen shard 4/8 had 20 passing scenarios and one failure:
  `with Auto on Codex, the answer names the model the CLI reports before the first word and keeps it to the end`.
  The reported tooltip was `Codex · GPT-6 Luna · Auto: the only connected subscription`.
- `engine/src/router.rs::pick_model` assigns `reason.autoOnly` when Auto has only Codex available.
- `engine/src/route.rs::candidates` requires Codex models to be in the reported model list. The recording
  `tests/fixtures/codex/chat-held.jsonl` reports the running model, but no model list, so there are zero routing profiles.
- `engine/src/engine/auto.rs::route_for` returns without classification for zero or one profiles.
  `after_route` uses `autoSingleProfile` only for exactly one usable profile, and `autoImmediate` only when
  more than one profile is available without a router result or timeout. Zero profiles preserves `autoOnly`.
- Inspected the existing `engine/tests/auto.rs::no_router_candidates_keep_the_default_reason`, which already
  asserts `reason.autoOnly` for an empty model list; no additional engine behavior or test was needed.
- Read all five locales for `autoDefault`, `autoOnly`, `autoSingleProfile` and `autoImmediate`.
  English maps `autoOnly` to `Auto: the only connected subscription`; `autoDefault` says `Auto: everyday default`.
  The other locales retain the same distinction.

The correction keeps every existing assertion: exact model name while held, empty answer before the first word
for Codex, required localized reason in the streaming tooltip, unchanged name and header height at completion,
and unchanged name and height after reopening. It neither accepts multiple reasons nor removes any assertion.
The failed CI output supplies the before-change regression evidence; the corrected scenario was not rerun locally.
