## Scope

Addresses the third independent review's P1 (conversation publication lacked parent-directory synchronization before
deleting sent task files) and note (the Save regression exercised only `save_copy`). The four retained PR fixes and
the moved-project repair deferral from `t515e.result.md` remain in place.

`store::replace_with` now calls the existing `Disk::flush` immediately after successful temporary-file sync and rename.
The existing default uses `File::open(directory)?.sync_all()?` on Unix and returns success without directory I/O on
Windows. Errors use the existing `Fault::of_write` mapping and propagate to the conclusion's checked `try_save`.
No new durable-save API or platform implementation is needed: the existing conclusion path already waits for this
checked publication, restores its in-memory closing box/estimate on failure, and deletes task files only on success.
Relative filenames use `.` as their parent. A sync failure after rename may leave the new conversation visible, but
is reported as failure and retains every task file; comments now distinguish that from a failure before replacement.

The new engine regression injects a recording disk through `Store::with_disk`, fails directory synchronization and
checks both sent task files byte for byte. It also checks the error and restored in-memory closing box, retries with
synchronization enabled, and records `temp sync`, `rename`, `dir sync`, then task deletion observed by the cleanup save.
The host regression dispatches the actual `save_file` command through a fake save dialog, selects a destination
hard-linked to another file, and checks the new destination bytes, unchanged source/sentinel and temporary-file cleanup.

The product map names both checks and the Unix durability requirement; the conversation design page clarifies the
same existing behavior. The PR's existing five-language what's-new entry already covers failed saves retaining files
and tasks. No screen, text, control, locale, stored schema, dependency or command signature changes.
