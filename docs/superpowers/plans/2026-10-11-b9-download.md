# B9: CLI Download Straight to Disk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The installer streams the Claude binary and the Codex archive to a file while it hashes them, so a 200 MB download no longer sits in memory, and the small metadata documents are read under a hard 4 MiB cap.

**Architecture:** `install.rs` gets a second kind of fetch, `Download` (`Fn(&str, &Path) -> io::Result<String>`), next to `Fetch`. Its network form `default_download` writes each received chunk to `install-tmp/download/<name>.part`, hashes it, closes the file and returns the hash; any failure deletes the file. `install_windows` takes both. Claude renames the verified `.part` file and runs the official installer on it; Codex unpacks the `.part` file into `codex-staging` and publishes that folder as before. A write failure is told apart from a network failure by a marker on the `io::Error`, so the key is `error.setup.install` or `error.setup.download`.

**Tech Stack:** Rust 2024 (tokio, reqwest 0.13, sha2, zip, flate2, tar), Tauri 2 shell, the Rust test runner `cargo t`. New dev-dependency: `sysinfo` (engine).

**Spec:** `docs/superpowers/specs/2026-10-11-faber-redesign-design.md`: B9 ("CLI download straight to disk"), B0 (commit 11), B10 (last sentence), A12, AI-25, and the Review log items about B9 (round 1 items 5 and 22 to 25; round 2 item 5). This is commit 11 of the order in B0 and is independent of the screen.

//! A loopback HTTP server for the download tests. It stands where the release host stands, so no test reaches the real
//! network. The handler writes the whole response itself, which lets a test send a body in steps, cut it short or
//! generate it without ever holding it.
#![allow(dead_code)]

use std::io::{self, BufRead, BufReader, Write};
use std::net::{Ipv4Addr, TcpListener, TcpStream};
use std::sync::Arc;
use std::sync::atomic::{AtomicBool, Ordering};
use std::thread::JoinHandle;
use std::time::Duration;

pub struct Server {
    /// `http://127.0.0.1:<port>`
    pub origin: String,
    stop: Arc<AtomicBool>,
    thread: Option<JoinHandle<()>>,
}

impl Server {
    /// Answers every request by calling `handler(origin, path, stream)`; the stream is closed when the handler returns.
    pub fn start(handler: impl Fn(&str, &str, &mut TcpStream) -> io::Result<()> + Send + Sync + 'static) -> Server {
        let listener = TcpListener::bind((Ipv4Addr::LOCALHOST, 0)).unwrap();
        listener.set_nonblocking(true).unwrap();
        let origin = format!("http://127.0.0.1:{}", listener.local_addr().unwrap().port());
        let (stop, handler) = (Arc::new(AtomicBool::new(false)), Arc::new(handler));
        let (thread_stop, thread_origin) = (stop.clone(), origin.clone());
        let thread = std::thread::spawn(move || {
            while !thread_stop.load(Ordering::Relaxed) {
                match listener.accept() {
                    Ok((mut stream, _)) => {
                        let (handler, origin) = (handler.clone(), thread_origin.clone());
                        std::thread::spawn(move || {
                            let _ = stream.set_nonblocking(false);
                            if let Some(path) = request_path(&stream) {
                                let _ = handler(&origin, &path, &mut stream);
                            }
                        });
                    }
                    Err(e) if e.kind() == io::ErrorKind::WouldBlock => std::thread::sleep(Duration::from_millis(5)),
                    Err(_) => break,
                }
            }
        });
        Server { origin, stop, thread: Some(thread) }
    }
}

impl Drop for Server {
    fn drop(&mut self) {
        self.stop.store(true, Ordering::Relaxed);
        if let Some(thread) = self.thread.take() {
            let _ = thread.join();
        }
    }
}

/// The path of a `GET`, read from the request line; the rest of the request head is read and dropped.
fn request_path(stream: &TcpStream) -> Option<String> {
    let mut reader = BufReader::new(stream);
    let mut line = String::new();
    reader.read_line(&mut line).ok()?;
    let path = line.split_whitespace().nth(1)?.to_string();
    loop {
        line.clear();
        if reader.read_line(&mut line).ok()? == 0 || line == "\r\n" {
            return Some(path);
        }
    }
}

/// The status line and headers of a 200 response whose body is `length` bytes, or, with `None`, runs until the
/// connection closes.
pub fn head(stream: &mut TcpStream, length: Option<u64>) -> io::Result<()> {
    match length {
        Some(n) => write!(stream, "HTTP/1.1 200 OK\r\nContent-Length: {n}\r\nConnection: close\r\n\r\n"),
        None => write!(stream, "HTTP/1.1 200 OK\r\nConnection: close\r\n\r\n"),
    }
}

/// A complete 200 response.
pub fn send(stream: &mut TcpStream, body: &[u8]) -> io::Result<()> {
    head(stream, Some(body.len() as u64))?;
    stream.write_all(body)
}

pub fn not_found(stream: &mut TcpStream) -> io::Result<()> {
    write!(stream, "HTTP/1.1 404 Not Found\r\nContent-Length: 0\r\nConnection: close\r\n\r\n")
}

/// A response that sends a redirect and nothing else.
pub fn redirect(stream: &mut TcpStream, to: &str) -> io::Result<()> {
    write!(stream, "HTTP/1.1 302 Found\r\nLocation: {to}\r\nContent-Length: 0\r\nConnection: close\r\n\r\n")
}
```

/// A file that accepts `left` bytes and then fails, like a disk that fills up.
struct FullDisk {
    file: std::fs::File,
    left: usize,
}

impl io::Write for FullDisk {
    fn write(&mut self, buf: &[u8]) -> io::Result<usize> {
        if self.left == 0 {
            return Err(io::Error::other("the disk is full"));
        }
        let wrote = self.file.write(&buf[..buf.len().min(self.left)])?;
        self.left -= wrote;
        Ok(wrote)
    }

    fn flush(&mut self) -> io::Result<()> {
        self.file.flush()
    }
}

#[tokio::test]
async fn the_part_file_grows_while_the_body_is_still_arriving() {
    const STEP: usize = 8 * 1024 * 1024;
    const STEPS: usize = 8;
    let block = |step: usize| vec![step as u8; STEP];
    let (sent_tx, mut sent_rx) = tokio::sync::mpsc::unbounded_channel::<usize>();
    let (go_tx, go_rx) = std::sync::mpsc::channel::<()>();
    let go_rx = Mutex::new(go_rx);
    let server = loopback::Server::start(move |_, _, stream| {
        loopback::head(stream, Some((STEP * STEPS) as u64))?;
        for step in 1..=STEPS {
            io::Write::write_all(stream, &block(step))?;
            let _ = sent_tx.send(step);
            if step < STEPS {
                go_rx.lock().unwrap().recv().map_err(io::Error::other)?;
            }
        }
        Ok(())
    });
    let dir = tempfile::tempdir().unwrap();
    let part = dir.path().join("big.part");
    let download = tokio::spawn(loopback_download(format!("{}/big", server.origin), part.clone(), server.origin.clone()));
    for step in 1..STEPS {
        assert_eq!(sent_rx.recv().await, Some(step));
        // A body that is buffered until the end leaves the file empty here and fails.
        let deadline = std::time::Instant::now() + std::time::Duration::from_secs(20);
        while std::fs::metadata(&part).map(|m| m.len()).unwrap_or(0) < (step * STEP) as u64 {
            let held = std::fs::metadata(&part).map(|m| m.len()).unwrap_or(0);
            assert!(std::time::Instant::now() < deadline, "after {step} of {STEPS} steps the file holds only {held} bytes");
            tokio::time::sleep(std::time::Duration::from_millis(10)).await;
        }
        go_tx.send(()).unwrap();
    }
    assert_eq!(sent_rx.recv().await, Some(STEPS));
    let hash = download.await.unwrap().unwrap();
    assert_eq!(std::fs::metadata(&part).unwrap().len(), (STEP * STEPS) as u64);
    use sha2::{Digest, Sha256};
    let mut sent = Sha256::new();
    for step in 1..=STEPS {
        sent.update(block(step));
    }
    assert_eq!(hash, format!("{:x}", sent.finalize()));
}

#[tokio::test]
async fn a_metadata_document_over_four_mebibytes_is_refused() {
    const LIMIT: usize = 4 * 1024 * 1024;
    let server = loopback::Server::start(|_, path, stream| match path {
        "/exact" => loopback::send(stream, &vec![b' '; LIMIT]),
        "/declared" => loopback::send(stream, &vec![b' '; LIMIT + 1]),
        // No length: the body runs until the connection closes, so only the count of bytes received can stop it.
        _ => {
            loopback::head(stream, None)?;
            io::Write::write_all(stream, &vec![b' '; LIMIT + 1])
        }
    });
    let fetch = |path: &str| {
        let (url, origin) = (format!("{}{path}", server.origin), server.origin.clone());
        async move { faber_engine::install::default_fetch(&url, Some(&origin)).await }
    };
    assert_eq!(fetch("/exact").await.unwrap().len(), LIMIT);
    for path in ["/declared", "/undeclared"] {
        let error = fetch(path).await.expect_err("A document over the cap must be refused");
        assert!(error.to_string().contains("larger than"), "{path}: {error}");
    }
}

/// A write that failed on this computer, as opposed to a network that failed. `install_windows` tells them apart.
#[derive(Debug)]
struct WriteFailure(io::Error);

impl std::fmt::Display for WriteFailure {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(f, "could not write the file: {}", self.0)
    }

/// Network fetch of a metadata document: at most `METADATA_LIMIT` bytes, held in memory.
pub async fn default_fetch(url: &str, loopback: Option<&str>) -> io::Result<Vec<u8>> {
    let mut res = get(url, loopback).await?;
    let too_big = || io::Error::other(format!("The document is larger than {METADATA_LIMIT} bytes: {url}"));
    if res.content_length().is_some_and(|n| n > METADATA_LIMIT as u64) {
        return Err(too_big());
    }
    let mut body = Vec::new();
    while let Some(chunk) = res.chunk().await.map_err(io::Error::other)? {
        if body.len() + chunk.len() > METADATA_LIMIT {
            return Err(too_big());
        }
        body.extend_from_slice(&chunk);
    }
    Ok(body)
}

/// Network download of a payload into the file at `dest`, one received chunk at a time, hashing as it goes. Returns the
/// SHA-256 in lowercase hex. The file is closed before this returns, and a failure deletes it.
pub async fn default_download(url: &str, dest: &Path, loopback: Option<&str>) -> io::Result<String> {
    download_with(url, dest, loopback, |path| std::fs::File::create(path)).await
}

/// `default_download` with the destination's writer supplied by the caller, so a test can make the disk fail.
pub async fn download_with<W: Write>(
    url: &str,
    dest: &Path,
    loopback: Option<&str>,
    create: impl FnOnce(&Path) -> io::Result<W>,
) -> io::Result<String> {
    let result = stream_to(url, dest, loopback, create).await;
    if result.is_err() {
        let _ = std::fs::remove_file(dest);
    }
    result
}

async fn stream_to<W: Write>(
    url: &str,
    dest: &Path,
    loopback: Option<&str>,
    create: impl FnOnce(&Path) -> io::Result<W>,
) -> io::Result<String> {
    let mut res = get(url, loopback).await?;
    let mut out = create(dest).map_err(write_failure)?;
    let mut hasher = Sha256::new();
    while let Some(chunk) = res.chunk().await.map_err(io::Error::other)? {
        hasher.update(&chunk);
        out.write_all(&chunk).map_err(write_failure)?;
    }
    out.flush().map_err(write_failure)?;
    // `out` is dropped here, before the caller sees the hash, so Windows lets the file be renamed, run or deleted.
    Ok(format!("{:x}", hasher.finalize()))
}

/// Every file under `root`, relative and with `/`, sorted.
fn tree(root: &Path) -> Vec<String> {

            if path.is_dir() {
                walk(&path, root, found);
            } else {
                found.push(path.strip_prefix(root).unwrap().to_string_lossy().replace('\\', "/"));
            }
        }

//! A payload goes to disk as it arrives, so the memory of the process does not grow with its size. This test sits alone
//! in its own file, hence in its own process: no other test shares the memory it reads. The workspace forbids `unsafe`
//! code, so it cannot count allocations; it reads the resident memory of its own process instead.

mod loopback;

use faber_engine::install::default_download;
use sha2::{Digest, Sha256};
use std::collections::BTreeMap;
use std::io::Write;
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::{Arc, Mutex};
use std::thread::JoinHandle;
use std::time::{Duration, Instant};
use sysinfo::{Pid, ProcessRefreshKind, ProcessesToUpdate, System};

const MIB: usize = 1024 * 1024;
const BLOCK: usize = 64 * 1024;

fn resident(system: &mut System, pid: Pid) -> u64 {
    system.refresh_processes_specifics(ProcessesToUpdate::Some(&[pid]), true, ProcessRefreshKind::nothing().with_memory());
    system.process(pid).expect("the test's own process is listed").memory()
}

/// Reads the memory of this process every 10 ms until it is stopped, and keeps the highest reading.
struct Sampler {
    stop: Arc<AtomicBool>,
    thread: JoinHandle<u64>,
}

impl Sampler {
    fn start() -> Sampler {
        let stop = Arc::new(AtomicBool::new(false));
        let thread_stop = stop.clone();
        let thread = std::thread::spawn(move || {
            let (mut system, pid) = (System::new(), Pid::from_u32(std::process::id()));
            let mut highest = resident(&mut system, pid);
            while !thread_stop.load(Ordering::Relaxed) {
                highest = highest.max(resident(&mut system, pid));
                std::thread::sleep(Duration::from_millis(10));
            }
            highest.max(resident(&mut system, pid))
        });
        Sampler { stop, thread }
    }

    fn finish(self) -> u64 {
        self.stop.store(true, Ordering::Relaxed);
        self.thread.join().unwrap()
    }
}

#[tokio::test]
async fn the_memory_of_a_download_does_not_grow_with_the_payload() {
    // The server writes 64 KiB at a time from one reused buffer and hashes as it goes; it never holds the body.
    let hashes = Arc::new(Mutex::new(BTreeMap::<usize, String>::new()));
    let server = loopback::Server::start({
        let hashes = hashes.clone();
        move |_, path, stream| {
            let mib: usize = path.trim_start_matches('/').parse().unwrap();
            loopback::head(stream, Some((mib * MIB) as u64))?;
            let (mut block, mut hasher) = (vec![0u8; BLOCK], Sha256::new());
            for index in 0..mib * MIB / BLOCK {
                block.fill(index as u8);
                hasher.update(&block);
                stream.write_all(&block)?;
            }
            hashes.lock().unwrap().insert(mib, format!("{:x}", hasher.finalize()));
            Ok(())
        }
    });
    let dir = tempfile::tempdir().unwrap();
    let mut peaks = Vec::new();
    for mib in [32, 160] {
        let (part, mut system, pid) = (dir.path().join(format!("{mib}.part")), System::new(), Pid::from_u32(std::process::id()));
        let baseline = resident(&mut system, pid);
        let sampler = Sampler::start();
        let hash = default_download(&format!("{}/{mib}", server.origin), &part, Some(&server.origin)).await.unwrap();
        let peak = sampler.finish();
        let deadline = Instant::now() + Duration::from_secs(10);
        let sent = loop {
            if let Some(sent) = hashes.lock().unwrap().get(&mib).cloned() {
                break sent;
            }
            assert!(Instant::now() < deadline, "the server never finished the {mib} MiB body");
            std::thread::sleep(Duration::from_millis(10));
        };
        assert_eq!(hash, sent, "the hash of the {mib} MiB body");
        assert_eq!(std::fs::metadata(&part).unwrap().len(), (mib * MIB) as u64);
        println!(
            "{mib} MiB body: baseline {} MiB, highest {} MiB, growth {} MiB",
            baseline / MIB as u64,
            peak / MIB as u64,
            peak.saturating_sub(baseline) / MIB as u64
        );
        peaks.push((baseline, peak));
        std::fs::remove_file(&part).unwrap();
    }
    let (small, large) = (peaks[0], peaks[1]);
    // A buffered body grows the process by the size of the body; a writer that also keeps every chunk, by 128 MiB between the two runs.
    assert!(large.1.saturating_sub(large.0) <= 24 * MIB as u64, "a 160 MiB download grew the process by more than 24 MiB");
    assert!(large.1 <= small.1 + 16 * MIB as u64, "the highest memory grew by more than 16 MiB from the 32 MiB body to the 160 MiB one");
}
```

## Deviations from spec

1. **The sampler is a thread, not a task.** The spec says "a sampler task". `default_download` writes to the file from the test's own async task, and a task on the same runtime would only run between those writes. A plain thread reads the memory on its own schedule, every 10 ms as specified.
2. **Three small public additions in `install.rs`: `download_with`, `write_failure`, `is_write_failure`.** The spec fixes `Download` as `Fn(&str, &Path) -> io::Result<String>`, so the error key (`error.setup.install` for a write, `error.setup.download` for the network) has to travel on the `io::Error` itself; the marker is the smallest way. `download_with` takes the writer from the caller so the "destination that fails after 1 MiB" test can exist without a full disk. `default_download` is `download_with` with `File::create`.
3. **The handle-release test opens the file exclusively instead of only renaming and deleting it.** Rust opens files with `FILE_SHARE_DELETE`, so on Windows a rename or delete succeeds even while Faber still holds a handle (checked: a leaked handle passed that version of the test). The test keeps the rename and delete the spec names, and first opens the file for writing with sharing off, which is what starting a program needs and what a leaked handle breaks. That check, and the exclusive open in the stand-in installer, can only fail on Windows.
4. **`F02_tls_transport` no longer asks github.com.** It sent a real HTTPS request. It now connects to a closed loopback port and checks the same thing (the client has TLS). This follows the rule that unit tests never reach the real network; the spec does not name this test.
5. **The file-progress test waits for the server instead of sleeping.** The spec says "with a pause after each step". The server announces each step on a channel, the test waits until the file holds that step (20 s limit), then lets the next step go. The assertion is the spec's: before the last step is sent, the file holds all earlier steps.
6. **"Deleted at once" is tested through the failure event.** The cleanup guard empties `install-tmp` at the end of every install, which would hide a missing delete. The rig records the files in `install-tmp` at the moment `failed` is reported, and the tests assert it is empty.
7. **The metadata cap also checks `Content-Length` first.** The spec asks for a cap. A declared length over 4 MiB is refused before reading; a body with no length is stopped by counting. Both are tested.
8. **No read timeout was added.** A server that stops answering still hangs a download, as it hangs a fetch today. The spec does not ask for a timeout and the interrupted-download cases it lists end in an error.
9. **The process-memory test takes about 15 s** in a debug build, because it hashes 192 MiB twice (server and client) without optimisation. The spec fixes the sizes; the workspace's dev profile was left alone.
