# `/` menu in the composer

Parity row T3 ([parity.md](../product/parity.md#talking-and-steering)). Typing `/` at the start of the message lists
what can run from there: the CLI's own commands that work without its terminal (for Claude Code the skills and the
commands it reports at session start; for Codex its app-server's list), the skills of the conversation, and Faber's own
actions that already exist elsewhere (never a second way: each item opens or runs the existing control). Filtered as
you type, run unmodified by the CLI. Read the 2026-10-19 inventories cited in parity.md for the lists.
