# The list of shortcuts (parity K1)

Row K1 of docs/product/parity.md: a sheet that lists every keyboard shortcut Faber has, opened with ? (outside a text
box) and from the help or Settings place the product map names. The keys stay fixed; the sheet reads them from the one
place the app defines them, so a new key cannot be missing from it.

Done when: a screen check opens and closes it by keyboard and a check fails when a key is defined but not listed; the
product map and docs/design are updated; a what's-new entry in five languages.
