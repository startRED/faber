# Move a chat into a project (parity F3)

Row F3 of docs/product/parity.md: a chat in the Chat area moves into a project from its right-click menu, keeping its
messages, title and pin; from then on it is a project conversation of that project (its folder, its checks and tools),
and its next turn starts there. Extends the conversation row's menu and the projects list; no new screen.

Done when: engine tests of the move (the record, the area, the CLI session carried or started fresh as each CLI allows,
a running chat refused until it stops); a screen check of the menu and the moved row; the product map and docs/design
are updated; a what's-new entry in five languages.
