# Export a conversation to a file (parity F4)

Row F4 of docs/product/parity.md: the conversation row's menu gets Export, which asks where to save with the system's
own save picker and writes the conversation as Markdown (messages, who said them, times; pictures as file names). No
share link and no server. Extends the conversation row menu.

Done when: an engine test of the Markdown from a fixture conversation and a screen check of the menu entry; the product
map and docs/design are updated; a what's-new entry in five languages.
