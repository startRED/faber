# The catalog tools a conversation uses, in two clicks

The owner asked on 2026-10-22 where to see the Catalog's tools being used, and could not find the one quiet line in a
reply's work log on a long project conversation (it shows only on the reply where a session started with a different
kit, `docs/design/conversation.md`, "Work log").

Show the kit a conversation has now, in Chat and Projects, at most two clicks from the conversation: each item's
`catalog.name.*` name, why it was picked (its job group), and a link to its Catalog detail, with a calm line when none is
in use ("No catalog tools in use in this conversation"). Extend what exists (the topbar's Context meter panel is in both
areas); no polling, no new process, no setting on a work screen. The product map, `docs/design/`, a what's-new entry in
every language, and a screen check that fails without the change.
