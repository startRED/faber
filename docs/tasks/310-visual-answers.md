# Visual answers beside the chat (parity M1)

Row M1 of docs/product/parity.md, with "visual answers" in docs/product/following.md and candidates D and E of
docs/research/2026-10-18-harness-output-ui/: when a reply makes a page, a chart or a small app, it opens beside the
chat in Faber's own view, sandboxed (no network unless the person allows it, no access to Faber), with each version kept
so the person can go back to an earlier one. Extends the running column's pane, like Faber's browser page. Size L:
split into steps that each land on their own; the look is taste, so show the owner a short card first.

Done when: engine tests of detecting a visual answer and keeping its versions; a screen check of opening one, its
sandbox and switching versions; the memory cost is measured; the product map and docs/design are updated; a what's-new
entry in five languages.
