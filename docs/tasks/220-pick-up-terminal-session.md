# Pick up a session started in the terminal (parity F5)

Row F5 of docs/product/parity.md: in a project, Faber lists the CLI's own sessions of that folder (the ones the person
started in a terminal, read from the list each CLI offers, never from its sign-in files) and opens one as a Faber
conversation that goes on where it was. Extends the new-conversation place of Projects; resuming uses each CLI's own
resume flag.

Done when: engine tests with fake session lists for both CLIs (listing, resume arguments, a missing session); a screen
check picks one up; the product map and docs/design are updated; a what's-new entry in five languages.
