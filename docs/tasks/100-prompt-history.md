Row T6 of docs/product/parity.md: in the message box, the up arrow on an empty box (or with the caret on the first
line) brings back the person's earlier messages, newest first, down goes forward again; a search over them (Ctrl+R in
the box) filters as you type. Extends the Composer (ui/Composer.tsx); the messages come from the saved conversations,
no new stored value unless one is needed. Both areas.
