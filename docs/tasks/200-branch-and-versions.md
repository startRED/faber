# Branch from any point, and the versions of a message (parity T7)

Row T7 of docs/product/parity.md: a message's menu offers "Branch from here" without editing, and an edited or retried
message shows small arrows between its versions (1/2, 2/2), each version keeping its own answers. Extends Branch (editing
already branches into a new conversation); one stored shape for both, no second history.
