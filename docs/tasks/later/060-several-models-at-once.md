Owner said yes. From the T3 Code study (`02-agent-progress.md`, fan-out): the person picks two or more models (any
connected vendor), the same request starts one background thread per model, each in its own worktree, shown side by side
in the thread list with the status rules of task 030; the person keeps one result and the others can be discarded.
Quota: the screen says up front how many models will run and Auto's pacing may refuse or reduce the count when a
subscription is nearly spent. Needs a worktree-per-thread flow; check the product map for what exists. Memory: one child
process per model, measured (R125). Words in every language; what's-new entry.
